# PR33 — OCR 框选光标高对比度优化

基线：最新 `origin/main`，`21a0807`（PR32）。验证日期：2026-10-16。

## 实际修改

- OCR 遮罩改用原生 Windows `.cur` 十字：深色外轮廓、白色内轮廓、青蓝色细芯。32/48/64/96 像素帧的热点分别为 (16,16)/(24,24)/(32,32)/(48,48)，与可见中心一致；32 像素帧实际图形占 23×23 像素，其余为透明留白。
- 光标嵌入 `SeleVox.App.dll`，通过 `Cursor(stream, scaleWithDpi: true)` 加载；缺失、损坏、I/O、权限及原生加载失败时回退 `Cursors.Cross`。每个遮罩拥有独立光标，关闭后清空属性并释放；共享系统回退光标不释放。
- 提供 `scripts/New-OcrSelectionCursor.ps1` 确定性重建原始像素资源，不依赖外部绘图工具。
- 保持物理鼠标坐标、DIP 转换、截图与裁剪、矩形、Esc、失焦取消及原有窗口关闭流程。没有新增窗口、鼠标 Hook、全局指针替换或系统设置修改；没有修改 OCR 引擎、TTS/LLM、权限、播放、安装器或发布工作流。
