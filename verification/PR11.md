# PR11 — 独立 TTS 音频生成工作台

日期：2026-10-14。基线：PR10 已合并的 `main` / `5ea0a4b`。本机 Windows x64、.NET 10、WPF、NAudio 3.1.0。

## 实现与操作

主设置底部及托盘都有“音频生成”入口，重复打开激活同一工作台；不设置主窗口 Owner，关闭主设置不会强制关闭工作台。关闭工作台取消生成、查询、保存和属于该窗口的缓存试听，释放正文/结果；重新打开恢复明确保存的默认参数和窗口位置，不恢复正文/音频。

默认试音使用固定中英文短文本，生成后经统一 ReadingSession / WASAPI 播放。生成使用编辑框正文；默认试音也会成为最后一次成功结果。试听和保存只打开缓存，不发合成请求。结果区固定在窗口底部，显示生成时的 Provider、Voice、参数和音频格式/帧数，修改草稿不会重标记结果；失败/取消保留上一次成功结果。

五个 Provider 复用已有参数和服务实现；Azure 与 Edge 使用原语音查询，MiMo 标签复用 `MiMoStyleTags` 和预设。Windows 本地语音缺失给出反馈。在线凭据仅从 Credential Manager 读取并显示已配置/未配置状态，有前往主设置的入口，不展示 Key。OpenAI-Compatible 地址始终使用当前主设置保存值。工作台参数不改日常 Provider、输出设备或自动上传权限。

`AudioGeneration.GenerateAsync(text, settings, cancellation)` 接收配置、输出已验证完整音频，操作代码不引用 WPF 控件或播放设备。Windows/Azure 以 800 UTF-16 字符预算按已有 Unicode 文本元素边界分段；其他 Provider 仍使用自己的完整合成/分段实现。只合并同格式样本，校验最终 RIFF/chunk 长度、编码、帧对齐和数据非空。总正文限制 32768 字符，总输出限制 256 MiB，已有 Provider 较低限制继续有效。MiMo 工作台固定使用完整 WAVE；未接入流式文件写入，不改实时 SSE/PCM 路径。

`GeneratedAudio.Open()` 创建独立只读流；`SaveAsync(path, overwriteConfirmed, cancellation)` 写同目录唯一临时文件，Flush 后提交。已有目标须经界面确认；未确认或目标在确认前不存在但保存时出现，提交不会覆盖。取消/异常清理临时文件。导出原始样本，不经过音量、重采样或 `StartupSilenceProvider`。合成和保存不打开声卡；试听才读取主设置当前输出/音量/起音补偿，并替换旧朗读和 AI 语音队列。统一暂停、继续、停止和设备错误处理保留。

工作台每窗口串行合成，等待请求可取消；代次及关闭检查拒绝非协作 Provider 的迟到结果。缓存播放在原 ReadingSession 的取消/释放路径运行，窗口关闭不会停止后来由其他入口替换的播放。工作台 JSON 只投影明确保存的 TTS 草稿和几何位置；不保留正文、生成音频、用户 LLM Prompt、Key 或自动授权。`settings.json` 数据结构未改变，旧配置兼容。
