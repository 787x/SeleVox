# PR14 — CLI / MCP 与 Agent 语音预设

日期：2026-10-14。基线：`82bf1dc`，PR13 已合并的 `main`。Windows 11 x64、.NET 10、普通用户会话。

## 实际修改

- 新增可发布的 Windows 控制台 `SeleVox.Cli.exe`，同一 EXE 提供 CLI 与官方 MCP C# SDK 2.2.0 stdio；没有 HTTP Server 或 Node/Python 依赖。
- CLI/MCP 共用 Agent 参数和当前用户专属 Named Pipe，通过桌面实例的 `AudioGeneration`、`SpeechAudio`、`ReadingSession`、`GeneratedAudio.SaveAsync` 和 `CloneLibrary` 执行；没有重写 TTS 请求或 WASAPI。
- 后台自动启动使用固定本地 WinExe 和 `--agent-background`；第二后台实例不触发显示设置。Windows shell 启动隔离调用者管道句柄，避免冷启动后 PowerShell JSON 管道或 MCP stdio 被背景进程持有。
- 独立 `agent.json` 保存 Agent 默认值和命名预设，逐字段继承、显式空值、模式/模型层级、Unicode、单次覆盖均经过校验；写入使用独占锁和原子提交。主设置、工作台文件和样本库格式兼容。
- Agent 在线上传独立控制，默认关闭。凭据及服务地址只读主程序配置；OpenAI-Compatible 授权绑定地址，普通参数不能覆盖地址或 Key。
- MiMo Preset / VoiceDesign / VoiceClone、自然语言、整体标签/唱歌、导演字段、句内脚本及长文本分段复用已有能力；克隆通过库内 ID 请求时编码，结果/预设不含参考音频。
- 一个活动 Agent 任务，无积压队列；当前桌面最近 128 个 Job 元数据，状态查询不重合成。GUI Stop、新朗读、旧 Job 停止、客户端取消及 MCP 断开均受统一会话所有权控制。
- Agent 播放严格使用有效配置中的设备；任一指定设备失败会释放已打开输出，不跳过或回退。WAV 导出没有播放器，也没有起音补偿。
- MCP 默认 12 个工具。按用户决定，`delete_preset` / `set_defaults` 可由 CLI 配置暴露，默认不暴露；即使启用 `set_defaults` 也不能开启云端授权、改导出目录/服务地址/工具开关。
- MCP 导出仅限配置目录，默认禁止覆盖，拒绝越界、额外数据流、junction/reparse point；持有目录句柄防替换，临时写入完成后原子提交。错误仅含安全代码/类型，工具回复提供 `structuredContent` 与 `isError`。

## 复跑方式

```powershell
dotnet build -c Release
./scripts/Publish-Windows.ps1
$env:SELEVOX_AUDIO_TESTS = '1'
dotnet test -c Release --filter 'FullyQualifiedName~AgentConfigurationTests|FullyQualifiedName~AgentExecutionTests|FullyQualifiedName~ReadingSessionTests|FullyQualifiedName~AudioGenerationTests|FullyQualifiedName~HttpSpeechTests|FullyQualifiedName~MiMoCreative|FullyQualifiedName~CloneLibraryTests|FullyQualifiedName~MultiOutput|FullyQualifiedName~AudioWorkbenchWindowTests|FullyQualifiedName~QuestionSessionTests|FullyQualifiedName~SettingsTests|FullyQualifiedName~AgentSecondInstance'

# 先关闭桌面实例，冷启动测试不会替用户强制结束进程。
$env:SELEVOX_AGENT_CLI = (Resolve-Path './artifacts/pr14-portable/SeleVox.Cli.exe').Path
$env:SELEVOX_AGENT_COLD_TESTS = '1'
dotnet test -c Release --filter 'FullyQualifiedName~ColdCliRedirectedOutput'
$env:SELEVOX_AGENT_COLD_TESTS = '0'
$env:SELEVOX_AGENT_TESTS = '1'
dotnet test -c Release --filter 'FullyQualifiedName~AgentDesktopTests&FullyQualifiedName!~ColdCliRedirectedOutput'

# 仅在用户明确允许发送固定测试内容并接受服务费用后执行。
$env:SELEVOX_AGENT_ONLINE_TESTS = '1'
dotnet test -c Release --filter 'FullyQualifiedName~AgentOnlineTests'
```

桌面测试会发声、临时改变 Agent 配置并恢复；不要与其他 Agent 调用并行运行，测试时勿手工修改同一配置。在线样本只使用固定测试文本，现有 Credential Manager Key 不输出。

## 权限边界、未验证项和限制

- Windows 当前用户、同权限级别限制使用 .NET `CurrentUserOnly`；服务端对本机管道和客户端进程另做校验。本机正常连接已实测；跨 Windows 用户、UAC 权限级别不匹配和另一机器尝试连接没有实际多账户/远程验收，不能把文档语义当作实测。
- 配置和导出限制是应用级约束，不隔离同一 Windows 用户的恶意进程；其仍可能直接修改自己的文件或编写其他客户端。不会暴露 OS 命令执行、任意文件读写/删除、系统默认设备修改或 Key 管理。
- Azure 未配置区域/音色，OpenAI-Compatible 没有已保存凭据，其真实服务调用未验证；相应已有协议与参数行为由受控回归验证，不称为真实在线成功。
- 真实音频测试证明播放状态/帧数/文件容器及所选输出链路可用，不能代替人工听音、声学同步或所有硬件拔插故障验收。没有真实关闭所有声卡；无播放器的合成路径及无效设备配置已直接验证。
- 实际桌面 Stop 消息、MCP 断开、受控 GUI 替换均已验证；用户点击托盘/工作台按钮、真实外部 UIA 自动朗读与 Agent 双向竞争、退出中的付费网络请求和异常断电未逐项人工验收。PR1–PR13 的全部桌面场景没有机械全量复跑。
- 最多一个活动 Agent 任务、4 个 IPC 连接、1 MiB 消息、256 MiB 完整音频、20 分钟任务上限；Job 状态不跨桌面重启保留，不缓存每个完成音频供再次播放。重复状态查询不产生请求，但重新提交会创建新任务。
- MCP 取消/退出取消其活动连接对应的任务；未使用 `--wait` 的 CLI 提交是有意脱离客户端的后台任务，正常 CLI 退出后继续。写响应失败时会取消未确认提交；无自动重发。
- 一次导出原子提交前检查取消。强制杀进程/断电可能留下 `.tmp`，不会留下被报告为成功的半成品 WAV；不提供断电事务恢复。MiMo 长句/长手写标签边界限制沿用 PR12。
- 新增工具暴露需要重启 MCP；关闭权限立即由桌面拒绝。Agent 默认在线上传及两项可选工具关闭，实际使用前请阅读 [CLI / MCP 说明](../docs/CLI-MCP.md)。
