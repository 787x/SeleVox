## PR #37 跨入口竞态与 CI 复验

- Auto Speak 在稳定捕获、去重、应用规则和自动 TTS 授权检查通过后，于自身等待开始前取消尚未提交的 OCR 延迟朗读。到期时仍重新校验选区。计时期间的已有播放由原会话继续处理。
- 同一可控时钟从 OCR 启动后前进 1 秒才启动 Auto Speak。到 OCR 原定的第 3 秒时 Fake TTS 调用数为 0，第 4 秒只有新选区合成一次。新选区在等待中失效时两个入口均无提交。普通点击、空选区、重复、UIA 失败、无授权或旧代次均保留 OCR，届时只合成 OCR 一次。各场景覆盖流式和非流式。
- GitHub [失败运行 44029720970](https://github.com/787x/SeleVox/actions/runs/44029720970) 对应 `f865c4a`，离线测试 534 通过、2 失败、1 跳过。两项用例及其相关实现当时与基线 `dca0315` 一致。本机在修改前定向执行 5 轮，每轮 3 项全部通过，未重现失败。

- 修复后两个曾失败用例定向执行 4 轮，每轮 3 项通过。Release 构建 0 警告、0 错误，相关定向测试 113 项通过，离线回归 538 项通过、1 项跳过、0 项失败。跳过项为未启用的 VB-CABLE 录音测试。本次未复跑交互桌面或真实音频。
