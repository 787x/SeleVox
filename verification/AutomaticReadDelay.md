# 自动朗读延迟验证

基于 `main` 的 `dca0315`，2026-11-17 在 Windows 11 x64 上验证 Release 构建。

- 主设置可立即保存 0～10 秒的延迟，每 0.5 秒一档。旧配置缺少字段时按 0 秒执行。只改延迟时保留正在播放的会话和主设置中其他未保存的编辑。
- Auto Speak 在选区有效、未重复且当前 Provider 允许自动朗读后等待。到期时用原本的操作类型重新检查代次、前台窗口、规则和权限，通过后才提交。OCR 先显示结果，再预检查、等待并提交。
