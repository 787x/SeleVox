# PR19 — GitHub Release 自动化与 Windows Portable

日期：2026-10-15；基线 main `14cb71f`（包含已合并 PR18 `5c09416`）。

## 修改

- Tag push 独立 Release Workflow，严格 Stable/RC 格式与 .NET 数值限制，远端 Tag 剥离 commit、当前 main 可达历史和准确构建提交校验；同 Tag 排队不抢占。构建只读，仅独立 publish Job 获 contents: write。
- Publish-Windows 可选 VersionTag，统一 App/CLI/Core 的 AssemblyVersion、FileVersion 和保留 RC 的 Product/InformationalVersion，不改 csproj、配置或业务行为。旧无版本调用兼容。
- 复用 PR18 独立发布/共享依赖 SHA-256/完整性/CLI 检查。生成单一 SeleVox 根目录 ZIP，临时实际解压；核对所有相对文件路径/数量/哈希、App/CLI apphost 与程序集版本，再次执行 Test-Publish（包含禁止全局 Runtime 回退的 CLI --help）；最终 ZIP 生成标准 SHA256SUMS。
- 普通 CI 只读使用测试版本 v0.0.0-rc.1，执行实际打包及针对性错误输入拒绝并上传 ZIP/checksum，保留 PR18 目录 Artifact 和 TRX。
- 发布通过 GITHUB_TOKEN / gh，fail-closed 查询重复 Release/Draft，不覆盖或删除，创建现有 Tag 的 Draft，上传两个文件后核对 Tag/commit/RC/资产数量、名称、大小与 GitHub digest，再重新检查 Tag 后公开。失败保留非公开 Draft。RC 不成为 Latest Stable。
- README、发布说明与首次功能概览 Notes 描述下载/校验/启动、CLI/MCP、自行配置 API Key、外装 VB-CABLE、无代码签名、Portable 用户配置行为和人工验收边界。
