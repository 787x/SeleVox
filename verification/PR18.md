# PR18 — GitHub Actions CI

日期：2026-10-15。基线：`fcb57c1`（PR17 合并后的最新 main）。

## 修改

- 新增 Windows CI：PR → main、push main、workflow_dispatch，windows-2025 x64 / .NET 10 SDK；只读 contents Token、checkout 不保留凭据，25 分钟总预算、同 PR/分支取消旧运行。
- 使用官方 [checkout](https://github.com/actions/checkout/releases/tag/v7.0.1)、[setup-dotnet](https://github.com/actions/setup-dotnet/releases/tag/v6.0.0)、[upload-artifact](https://github.com/actions/upload-artifact/releases/tag/v7.0.2)，固定完整 commit SHA。无 PR secrets、pull_request_target、第三方脚本或 continue-on-error。
- 审查并为 30 个离线测试类添加 Offline Trait。真实 Credential Manager 用例另标 WindowsCredentials 并排除；虚拟 Capture 用例保留既有 opt-in，清除 SELEVOX_* 后跳过。WPF/桌面/热键/Hook/真实声卡/在线服务/驱动验收入口保留，不将这些测试当成离线通过。
- Test-CI.ps1 执行 Release 非空离线集合；Test-CIReport.ps1 从 TRX 输出实际计数并写 Actions 摘要，失败/空集合/无成功报告会抛错；总工作流失败，已有 TRX 仍上传。
- Publish-Windows.ps1 默认目录改为 artifacts/win-x64，必须为空。临时独立发布两端，验证共享文件 SHA-256 相同才合并，检查成功才复制到输出；不会从仓库根目录泛打包。
- 实际发现 CLI/Core 与 WPF 运行包的 Microsoft.VisualBasic.dll 不同。组合发布时通过 SeleVoxCombinedPublish 条件引用 WindowsDesktop 框架，让两端解析相同运行时包；正常 CLI 构建不改变。发布过程隔离 build/obj，不锁现有运行实例。
- 增加 EdgeTransport/NOTICE.md 和明确的 LICENSE 发布复制。Test-Publish.ps1 检查 EXE、两端 deps/runtimeconfig、self-contained win-x64、全部声明的 runtime/native/resource 文件、WPF、OCR 双语模型/x64 原生 DLL/VC 运行库及许可；拒绝已知配置/凭据/样本/音频/测试输出/驱动。独立临时工作目录实际执行 CLI --help，15 秒预算，检查返回码和帮助内容，不启动桌面。
- 测试报告和完整便携目录 Artifact 保留 7 天；README 说明 CI 范围、发布方式和仍需本地人工验收项。

## 限制

CI 不验证交互式 WPF、UIA 桌面选区、真实 OCR 截图/字体识别质量、热键/Hook/托盘、WinRT 安装语音、WASAPI/声学同步、VB-CABLE Capture/驱动安装、跨用户凭据及收费 TTS/LLM 服务。CLI --help 与受控 Agent/MCP 执行层回归不替代实际 MCP 客户端连接桌面验收。沿用 PR14/PR15/PR17 的本地 opt-in 和人工流程。
