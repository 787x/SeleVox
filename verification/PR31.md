# PR31 — 托盘开机自启快捷开关

基线：PR29 已合并的 `origin/main`，`4d7203e`。本轮验证日期：2026-10-16。

## 实际修改

- Auto Speak / Auto Ask 附近新增“登录 Windows 时自动启动”。初始值来自已保存配置；点击使用当前已保存配置只修改 `StartWithWindows`，成功后更新托盘、主窗口控件及主窗口保存基线。失败使用现有托盘气泡及窗口提示，不打开或激活设置窗口。
- `SetStartupSettings()` 只同步自启状态，保留其他未保存编辑；普通设置保存后的 `SetAutomaticSettings()` 也同步自启。失败恢复主窗口自启控件，托盘不提前切换勾选。
- 仅自启变化（含内容相同但重新创建的设置集合）走短路径，跳过取消选区/问答/自动朗读、刷新 OCR 提示及安装鼠标监听。其他业务配置保存仍沿用原有行为。
- `StartupRegistration.ApplyAndSave()` 复用 PR29 的路径、命令和归属检查；配置保存失败时恢复实际操作前的 Run 值及类型，保留旧 Portable 路径。注册失败不保存配置；不改写非本应用值。恢复本身失败时明确提示检查 Windows 启动设置，不报告成功，也不覆盖并发出现的非本应用命令。
- 不改配置格式、安装器、发布资产、后台/单实例启动机制或其他 TTS/LLM 功能。勾选表示已保存配置，不保证 Windows 启动管理器允许启动。
