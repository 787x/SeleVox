# PR12 — MiMo 高级音频生成控制台

日期：2026-10-14。基线：最新 `origin/main` / `ae69490`（PR11）。Windows x64、.NET 10、WPF、NAudio 3.1.0。

## 实现与工作流

- 工作台左侧滚动输入 / 参数，右侧结果及固定操作；最小 900×620，较长结果单独滚动。五种 Provider 保留原有生成、默认试音、缓存试听和 WAV 保存。
- MiMo 模式选择 Preset Voice / VoiceDesign / VoiceClone；预置模式提供自然语言、导演、整体风格、句内音频标签和唱歌。其他模式只提供自然语言 / 导演输入，隐藏预置音色与不适用标签控件。原有整体标签搜索、多选、自定义和唱歌互斥规则保留。
- 句内脚本使用多行正文编辑器，11 个标签按钮插入光标处 / 选区前，不删掉已选正文；手动标签仍可编辑。正文下方显示实际 `user` 与逐段 `assistant` 文本，含前缀、字符数和分段数量。空正文、超长正文、非法控制字符及无效分段值明确拒绝。
- 导演模式角色 / 场景 / 指导组合成自然语言，有电台示例。请求在启动时捕获文本、模式、指令、分段值及来源选择；字段修改不改变进行中的请求。
- VoiceDesign 使用 `mimo-v2.5-tts-voicedesign`；必填描述进入 `user`，原文进入 `assistant`，仅设置 WAV，不附加预置 voice、唱歌前缀或自动润色参数。
- VoiceClone 使用 `mimo-v2.5-tts-voiceclone`；所选样本读入内存快照，WAV / MP3 分别用 `data:audio/wav;base64,` / `data:audio/mpeg;base64,` 放入 `audio.voice`。生成过程中切换 / 删除库内样本不修改已经构建的请求。
- 上传复制至本地库；录音使用系统默认麦克风，PCM16 / 24 kHz / mono，最多 30 秒，停止后验证再加入库。关闭窗口取消并丢弃未完成录音；录音与上传不调用云端服务。
- VoiceDesign 成功结果可直接存为克隆源，无再次合成；按名称保存后自动选择，切换 VoiceClone 可立即生成。库为工作台目录下的 `clone-samples`，`samples.json` 保存名称、来源、库内绝对路径和创建时间。支持试听与删除；删除不触碰上传原文件，元数据提交失败会恢复重命名的音频，不覆盖损坏索引。
- 参考样本严格解码并校验 5–30 秒，Base64 ≤ 10 MiB；因此原文件限制约 7.5 MiB，比任务提出的原文件 10 MB 更保守。无效格式、缺失 / 不可读取文件、大小和时长错误使用安全反馈，不展示异常中的敏感路径或请求正文。
- MiMo 完整生成自动分段默认开启，上限 50–3000 UTF-16 字符、默认 3000；同时遵守原有单段 3000 UTF-8 字节预算（扣除标签前缀）。沿用自然句边界与 Unicode 文本元素切分，保留原文；关闭后超过任一预算明确拒绝。组合音色 / 风格指令最多 3000 UTF-8 字节，正文 32768 字符、单响应 48 MiB、MiMo 合并音频 64 MiB 等原有上限保留。其他 Provider 及日常 SSE 分段路径不改。
- 最后成功结果保留生成时参数；输入修改提示旧结果仍保留。试听、保存、存克隆源均复用结果；失败 / 取消不丢旧结果。代次检查、串行生成、关闭取消沿用 PR11，Reference Base64 不持久化、不保留在结果配置。
- 显式保存工作台默认值包含模型、音色描述、最终风格指令和分段值；正文和参考 Base64 不保存，样本库是用户明确创建的本地资产。导演结构字段不单独持久化，重新打开时可在自然语言输入里看到之前保存的最终指令。日常设置和自动云端授权不改。

协议依据：[MiMo 官方 TTS 文档](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)。录音使用当前依赖版本的事件接口：[NAudio v3.1.0 WasapiRecorder](https://github.com/naudio/NAudio/blob/v3.1.0/src/NAudio.Wasapi/WasapiRecorder.cs)；该版本异步枚举会略过 Silent 包，事件接口提供零值包，避免录音中的停顿被删掉。

## 调试期间的失败与修复

- 首轮新增测试发现无效 MP3 的 `InvalidDataException` 未转换，已补充安全反馈。
- 新默认值校验顺序使原“未保存”错误提示回归，已恢复原先先检验有效性的顺序，原 PR11 默认值测试全通过。
- 首轮真实录音失败：异步枚举略过 Silent 包；改用事件录音保留静音。后续一轮录音为 4.94 秒，测试计时包含硬件启动，触发正确的最低 5 秒拒绝；有效录音测试等待提高到 8 秒。最终两轮真实录音及最终 Windows 组通过。未放宽产品的 5–30 秒限制。
