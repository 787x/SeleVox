# PR15 — TTS / LLM Provider 可用性诊断

日期：2026-10-14。基线：`41d899c`（合并 PR14 的最新 `origin/main`）。Windows x64、.NET 10。

## 实际修改

- 主设置增加独立服务检测窗口，六项服务分别预检查 / 主动检测。未检测、配置就绪、检测中、成功、失败、取消、结果过期分开显示；结果包含目标、模型 / 音色、模式、耗时、最近时间和脱敏错误分类。
- 使用保存配置及地址隔离的凭据快照。草稿未保存时阻止检测；保存配置、更新 / 清除 Key、草稿变化及窗口关闭会使旧结果失效。程序内更新 Key 立即失效；外部凭据更新每 500 ms 通过本地快照比较识别。不持久化健康状态或输入 / 输出。
- TTS 复用现有合成协议和严格 WAVE 校验。固定中英短句避免英文 Windows 语音对纯中文产生空音频；空、截断及错误格式仍失败。MiMo 预置流式复用 SSE 并消费有界环形缓冲，不创建播放器；只在完整流正常返回且 PCM 非空 / 帧对齐 / 消费完成后成功。
- VoiceDesign 固定合法诊断描述；VoiceClone 不自动取样或上传，报告缺少明确选择和上传确认，指引到既有工作台。三个模型和流式 / 非流式结果不混用。
- LLM 复用 ChatCompletionClient，固定 Prompt / 问题，原样使用模型、Thinking 和 Streaming。增加可选严格响应模式检查，仅诊断启用；普通问答保持既有兼容行为。完整最终回答才成功，不触发问答会话或朗读。
- 独立取消与 90 秒预算、单项有限并发、不排队 / 重试 / 切换服务。沿用协议大小限制；Azure 改为有界响应读取并保留整个合成 60 秒预算。
- UserFeedbackException 增加结构化安全错误分类 / HTTP 状态；HTTP 401/403、429、400/404/422、5xx、连接、超时、无效响应可区别显示，无本地化字符串解析。URL 仅显示 origin，隐藏可能携带秘密的路径。

## 未验证与限制

- **未执行真实 Azure、Edge、MiMo 或 OpenAI-Compatible TTS / LLM 在线调用**，没有据模拟 HTTP 宣称线上可用，也没有沿用 PR14 的在线结果作为本次通过。需要用户在当前凭据 / 模型下明确点击检测，可能收费；各模式单独记录。
- VoiceClone 的样本选择和上传确认沿用工作台；诊断窗口不提供克隆上传检测，始终显示条件未满足。VoiceDesign 的固定描述不验证用户自定义描述质量。
- 未重新执行发布 EXE / MCP stdio、真实 Auto Speak / Ask、托盘 / 全局热键完整人工交互；相关受影响逻辑有自动回归，PR15 未改其捕获或任务实现。
- 结果只代表该次调用完成；不验证长期 SLA、音色效果、回答语义质量或自定义 System Prompt。可用语音语言与固定中英测试句仍可能不匹配，空音频会如实报告失败。
- 配置快照比较保守包含全部已保存 Settings，因此无关设置保存也可能使历史结果过期。外部凭据更新识别间隔约半秒，程序内更新立即失效。
