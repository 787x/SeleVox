## 实现范围

- Auto Speak 默认关闭；设置和托盘共享保存入口，立即生效并持久化。旧 PR1 JSON 无新字段时加载为关闭、空白名单。
- 应用规则使用 `QueryFullProcessImageName` 获取的完整路径，不按进程名匹配。设置中点击“切换后添加前台应用”，十秒内切换到目标窗口；识别或前台稳定校验失败时不添加。规则可单独开关、删除。
- `WH_MOUSE_LL` 只处理手势与安排任务，始终调用 `CallNextHookEx`。左键拖选/双击才触发；鼠标按下、右键、滚轮、前台和焦点事件取消待处理捕获。关闭模式和退出释放鼠标/WinEvent Hook。
- 复用 PR1 UIA 捕获。自动读取另外校验鼠标起点命中的祖先链、操作控件类型、拖选线段与选区矩形相交和焦点 runtime ID，经过有限重试确认连续两次选区文本稳定。手动捕获不要求鼠标命中及矩形，保持原路径。
- 有效选区提交前去重并核对代次/规则/前台；无效捕获不调用 ReadingSession。停止、手动朗读、修改规则、关闭模式取消待处理捕获。关闭模式取消未播放的自动合成，保留已开始的播放。自动错误无气泡通知。
- UIA-only：未实现剪贴板回退，不模拟复制、不修改剪贴板；不涉及 OCR、LLM、网络 TTS 或多设备。

## 人工验收清单

Edge 可打开仓库内 `verification/PR2.html`，其中提供固定 A/B/C 文本、可编辑控件、普通按钮与空密码控件；页面不访问网络。该页面已准备，未将它的实际浏览器兼容性记为通过。

1. 关闭自动模式，在记事本拖选不发声；Ctrl+Alt+R/P/X 保持手动朗读/暂停继续/停止。
2. 添加记事本和 Edge 完整路径，开启模式，分别测试拖选与双击；保持原窗口焦点。再在未列入白名单的编辑器中选择文字，确认无自动朗读。
3. 逐应用禁用、移除后立即不触发；重新添加立即生效。检查托盘/设置开关同步，重启规则与开关保持。
4. 播放长段内容时，普通点击、按钮、滚动条、窗口标题拖动、无选区、重复文本、未允许应用选择均不打断。新的有效选区应替换播放。
5. 快速连续选择 A/B/C、在稳定等待中切换窗口或同窗口焦点、Stop、关闭模式，确认旧结果不迟到发声。关闭模式前已经播放的音频继续，Stop 后结束。
6. 密码输入框不读取；键盘选区用手动热键；关闭设置窗口后托盘/热键继续可用，从托盘退出后重新启动无资源冲突。
